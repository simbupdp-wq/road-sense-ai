# RoadWatch AI 🚦

AI-assisted traffic video analysis to identify potential near-miss events
and highlight road segments that may need safety review.

## Problem
Dangerous road interactions may go unnoticed until an accident occurs.
Manual traffic video review can be time-consuming.

## Proposed Solution
RoadWatch AI analyzes traffic videos to detect and track road users,
flag potential near-miss events, show timestamps and evidence, and
calculate a basic road danger score.

## Planned Features
- Traffic video upload and analysis
- Vehicle and pedestrian detection
- Object tracking
- Candidate near-miss event detection
- Event timestamps and severity levels
- Annotated video evidence
- Road danger score
- Hotspot map (if time permits)

## Technology
- Python, YOLO, OpenCV
- ByteTrack
- FastAPI
- React, Vite, Tailwind CSS
- Leaflet
